# shuihu-rom-lab · 水浒传 MD 简易版改造

世嘉 MD《水浒传》（1995，战棋 SLG）**简易版 ROM 改造**的参数化构建脚本：我方高基础数值、快速升级、高成长、高金币、全 9 格射程，**敌方保持原版强度**——靠地址段判据（敌方槽位 ≥ $FFEA80）在重算函数入口分流，一个补丁同时管住面板、升级与伤害。

## 🚀 使用

```bash
python tools/build_v9.py <原版ROM路径> [输出目录]
# 例: python tools/build_v9.py shz.md ./build
```

- 产出两个完整 ROM（各 2,097,152 字节）：`水浒传_简易版_v9.bin`（正式版）与 `水浒传_验证版_我方攻击250_v9.bin`（验证版，职业 0 攻击初始值 250，用于快速确认补丁生效）
- 脚本内置白名单断言：构建后逐区间回读，白名单外有任何字节变动直接报错拒绝出片
- 直接在模拟器打开成品 bin 即可，无需打补丁；测试建议新开游戏
- 依赖：Python 3.8+（纯标准库，无第三方依赖）

## 🛠 技术要点

- **数据流**（Ghidra/REA 反编译实证）：攻击结算读战场条目（$FFE780 起，0x40 字节/人）+0x14 为伤害基值；重算函数 $14C80 有 7 个调用点，敌军由专例程从关卡表整块拷入槽 12 起
- **分流判据**：`move.w a2,d1` + `cmpi.w #$EA80,d1` + `bhs.s`——数据寄存器比较，语义无歧义；d1 在钩子后先写后读，clobber 安全
- **编码教训**：capstone 的 m68k 渲染不可全信（cmpa 丢括号、movea/move 混淆），每条手写指令必须用编码手册逐位复核并在脚本里字节断言锁死
- 详细逆向过程见 Release 附件资料包内的使用说明
